# Rise & Verse 0.2.1 — testing update

1. [Download Rise & Verse 0.2.1](https://github.com/P1NKMAN666/verse-alarm/raw/refs/heads/main/downloads/RiseAndVerse-0.2.1-debug.apk) on your tablet and choose **Update/Install**. Do not uninstall the old app; the application ID and signing key are retained so alarms/settings remain.
2. When adding/editing an alarm, scroll the **hour, minute and AM/PM** columns. The hour uses **1–12**.
3. To type, **tap the selected hour or minute itself**. The keyboard opens for that field. There is no keyboard icon, typing button or separate typing screen.
4. Tap **Next / Susunod**, then save your repeat days. `12 AM` means midnight; `12 PM` means noon.

## Redmi Pad SE background setup

The reported HyperOS issue remains unconfirmed on the physical tablet. In system settings, allow Background autostart for Rise & Verse and set its battery usage to No restrictions if available. Allow Alarms & reminders, notifications and full-screen alarms. These system settings cannot be silently enabled by the app.

After configuration, reopen the app, set an alarm 2–3 minutes ahead, clear Recent Apps before it triggers and test while awake. Menu names vary with HyperOS versions. Force stop, shutdown and vendor restrictions can prevent alarm delivery or recovery. This update changes the time picker; it does not claim a new fix for HyperOS background restrictions.

The APK remains in the repository's downloads folder during testing. A formal GitHub Release/tag will be created only for the approved final release.
